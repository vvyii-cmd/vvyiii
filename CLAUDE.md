# Project conventions

- All content pushed to GitHub must be in English: code, comments, UI copy, README and other docs, commit messages, and PR titles/descriptions.
- This is a design prototype. Never commit real company data, exports (CSV/JSON dumps), credentials, or API keys. Use clearly fake placeholder data.
- Keep the app deployable as a static export: no server-side features (API routes, server actions, cookies) without updating the deployment setup first.
